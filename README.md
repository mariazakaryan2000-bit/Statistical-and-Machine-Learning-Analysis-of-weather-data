# Statistical-and-Machine-Learning-Analysis-of-weather-data
This project focuses on analyzing the impact of atmospheric conditions (Temperature, Humidity, Wind Speed, Pressure, and Visibility) on perceived body temperature. It features a complete pipeline:

Preprocessing: Data cleaning and standardization.

EDA: Correlation analysis, normality testing, and PCA visualization.

Modeling: Comparative analysis of OLS, KNN, and SVM regressors to determine the most accurate model for thermal sensation prediction.
